## Trailer

**Note from @Koschi:**

This is an introduction video for Kursal, a P2P fully decentralized messaging app. This was my first time making a video using Blender animations and DaVinci Resolve, but I'm happy with how it turned out :) 

All visuals were made in Blender by me and myself, and same thing for the sound editing in DaVinci Resolve.

I included a lot of references to movies and books like Tron Legacy and 1984 by George Orwell, which both fit well with Kursal's concept in my opinion.
Anyway, all the credentials for stuff like 3D models and sound effects/musics were listed at the end of the video.

This idea first came to me when watching TV with a friend and complaining about the low-quality ads with no concept behind them, so me and my friend joked about doing an ad for Kursal and here we are today !

DISCLAIMER: This project only includes the video. The entire app and website were made by @KodeurKubik
